# 1. Context

**Problem:**
ToolCNC hiện thiếu 3 tính năng quan trọng để nâng cao trải nghiệm B2B và tăng hiệu quả SEO: (1) Khách hàng doanh nghiệp chưa thể gửi yêu cầu báo giá số lượng lớn, (2) SEO hoàn toàn tĩnh không có Sitemap/Schema.org tự động, (3) Khách hàng không thể so sánh nhiều sản phẩm cùng lúc.

**Affected Modules:**
- `pages/product-detail` — thêm nút "Yêu cầu báo giá" và nút "So sánh"
- `pages/product-catalog` — thêm nút "So sánh" trên product card
- `shared/components` — thêm `quotation-modal`, `compare-bar`, `compare-page`
- `services` — thêm `quotation.service.ts`, `compare.service.ts`, `seo.service.ts`
- `models` — thêm `quotation.model.ts`, `compare.model.ts`
- `app.routes.ts` — thêm route `/compare`
- `app.config.ts` / `index.html` — SEO meta tags động, sitemap

**Non-Goals:**
- Thanh toán trực tuyến cho đơn báo giá (xử lý offline qua admin)
- Tích hợp email server thực (backend xử lý, frontend chỉ POST request)
- So sánh quá 4 sản phẩm cùng lúc
- Google Analytics / Tag Manager

# 2. Constraints

**Language:** `TypeScript (Angular 17+ Standalone)`
**UI Library:** `ng-zorro-antd`
**Architecture:** `Feature-based standalone components, inject() pattern`

**Rules:**
- Tất cả service dùng `inject()` thay vì constructor injection
- Không dùng NgModule — chỉ standalone components
- Tất cả HTTP call trong service, không trong component
- State tạm thời (compare list) lưu trong `signal()` hoặc `BehaviorSubject`
- Không thêm thư viện ngoài nếu ng-zorro đã hỗ trợ

# 3. Conventions

**Naming:**
- Components: `feature-name.component.ts` — PascalCase class
- Services: `feature-name.service.ts` — PascalCase class
- Models/Interfaces: `feature-name.model.ts` — PascalCase interface
- Constants: `UPPER_SNAKE_CASE`

**Error Handling:**
- Subscribe với `{ next, error }` — không để empty error handler
- Hiển thị lỗi qua `ToastService.showError()`
- Loading state: boolean flag `isLoading`, hiển thị qua `<app-loading>`

**Pattern mẫu từ codebase:**
```typescript
// Service pattern
@Injectable({ providedIn: 'root' })
export class FeatureService {
  private http = inject(HttpClient);
  private authService = inject(AuthService);
  private apiUrl = `${environment.apiUrl}/api/v1/...`;
  private getAuthHeaders() { ... }
}

// Component pattern
export class FeatureComponent implements OnInit {
  private service = inject(FeatureService);
  isLoading = false;
  ngOnInit() { this.load(); }
}
```

# 4. Contracts

## Interface: `QuotationRequest`
```
QuotationRequest {
  customerName:  string   — required, non-blank
  customerEmail: string   — required, valid email format
  customerPhone: string   — required, 10-11 digits
  companyName:   string   — optional
  productId:     number   — required, > 0
  productName:   string   — required (denormalized for email)
  variantId:     number?  — optional, null nếu không có biến thể
  quantity:      number   — required, >= 1
  note:          string?  — optional, max 500 chars
}

QuotationResponse {
  id:        number
  status:    'PENDING' | 'REVIEWED' | 'SENT'
  createdAt: string (ISO)
}
```

## Interface: `CompareProduct`
```
CompareProduct {
  id:          number
  name:        string
  imageUrl:    string
  price:       number
  brand:       { name: string }
  category:    { name: string }
  specs:       string?  — JSON string của thông số kỹ thuật
  stock:       number
}

CompareState {
  products: CompareProduct[]   — max 4 items
}
```

## Service: `QuotationService`
```
submitQuotation(request: QuotationRequest): Observable<QuotationResponse>
  - pre: request.productId > 0, email hợp lệ, quantity >= 1
  - post: trả về QuotationResponse với status='PENDING'
  - throws: HTTP 400 nếu thiếu field bắt buộc

getAdminQuotations(page, size): Observable<PagedResponse<QuotationResponse>>
  - pre: user phải có role ADMIN
  - post: trả về danh sách phân trang
```

## Service: `CompareService`
```
addToCompare(product: CompareProduct): void
  - pre: products.length < 4
  - post: product được thêm vào danh sách, không trùng lặp

removeFromCompare(productId: number): void
  - post: product bị xóa khỏi danh sách

clearCompare(): void
  - post: danh sách rỗng

isInCompare(productId: number): boolean
  - returns: true nếu product đã trong danh sách
```

## SEO Meta Contracts
```
SeoMetadata {
  title:       string  — max 60 chars
  description: string  — max 160 chars
  keywords:    string  — comma separated
  ogImage:     string? — URL ảnh đại diện
  canonical:   string  — full URL của trang hiện tại
  schema:      object? — JSON-LD schema markup
}
```

# 5. Target Architecture

## Feature 1: B2B Quotation Flow
```
ProductDetailComponent
  → [Nút "Yêu cầu báo giá"]
    → QuotationModalComponent (NzModal)
      → QuotationService.submitQuotation(request)
        → POST /api/v1/quotations
      ← QuotationResponse → ToastService.showSuccess()

AdminLayout
  → /admin/quotations (AdminQuotationsComponent)
    → QuotationService.getAdminQuotations()
    → Hiển thị bảng + cập nhật status
```

## Feature 2: SEO Automation
```
Router.events (NavigationEnd)
  → SeoService.updateMetadata(route.data['seo'])
    → Title.setTitle()
    → Meta.updateTag() — description, keywords, og:*
    → updateCanonical() — <link rel="canonical">
    → updateSchema() — <script type="application/ld+json">

ProductDetailComponent.ngOnInit()
  → SeoService.setProductSchema(product)
    → Sinh JSON-LD Product schema với price, availability, brand

/sitemap.xml  → Backend endpoint (note trong plan, không triển khai frontend)
```

## Feature 3: Product Comparison Flow
```
ProductCardComponent / ProductDetailComponent
  → [Nút "So sánh"] (click)
    → CompareService.addToCompare(product)
      → BehaviorSubject<CompareProduct[]> cập nhật

CompareBarComponent (fixed bottom bar, hiện khi >= 2 sp)
  → CompareService.compareList$ (async)
  → [Nút "So sánh ngay"] → navigate('/compare')
  → [X] → CompareService.removeFromCompare(id)

ComparePageComponent (/compare)
  → CompareService.compareList$
  → Render bảng so sánh dọc (thuộc tính theo hàng, sản phẩm theo cột)
```
